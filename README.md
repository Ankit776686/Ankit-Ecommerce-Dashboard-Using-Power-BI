## 📌 Project Overview

The **Ankit E-Commerce Sales Dashboard** is an interactive business intelligence project developed to analyze and visualize e-commerce sales data.

The dashboard provides a clear overview of business performance by tracking important metrics such as **Total Sales Amount, Profit, Quantity, and Average Order Value (AOV)**.

It helps users understand sales performance across different **states, product categories, customers, payment modes, months, and sub-categories**. The main goal of this project is to transform raw e-commerce data into meaningful insights that can support better business decisions.

## 🎯 Project Objective

The primary objective of this project is to create an interactive dashboard that helps analyze e-commerce business performance.

The dashboard is designed to answer important business questions such as:

- Which states generate the highest sales?
- Which product categories have the highest demand?
- Which customers contribute the most to total revenue?
- Which payment modes are most preferred by customers?
- How does profit change from month to month?
- Which product sub-categories generate the highest profit?

## 📊 Dashboard Features

### 🗺️ Sales Analysis by State

The dashboard compares the total sales amount across different states.

The analysis includes:

- Madhya Pradesh
- Maharashtra
- Uttar Pradesh
- Kerala

This visualization helps identify the geographical regions contributing the most to overall sales.

---

### 🏷️ Quantity Analysis by Category

A donut chart is used to analyze product quantity distribution across different categories:

- Clothing
- Electronics
- Furniture

This helps in understanding which product categories have higher customer demand.

---

### 👤 Customer-Wise Sales Analysis

The dashboard compares the sales amount generated by different customers.

This analysis helps identify valuable customers and understand customer purchasing behavior.

---

### 💳 Payment Mode Analysis

Customer payment preferences are analyzed using different payment methods:

- Cash on Delivery (COD)
- UPI
- Credit Card
- Debit Card

This visualization provides insights into the most commonly used payment methods.

---

### 📅 Monthly Profit Analysis

The **Profit by Month** chart displays the monthly profit performance of the business.

It helps identify:

- Profitable months
- Loss-making months
- Monthly performance trends

This information can help businesses improve their future sales and marketing strategies.

---

### 📦 Profit Analysis by Sub-Category

The dashboard analyzes profit generated by different product sub-categories.

Some of the analyzed sub-categories include:

- Bookcases
- Tables
- Accessories
- Saree
- Electronic Games

This helps identify which products contribute the most to overall profit.

---
